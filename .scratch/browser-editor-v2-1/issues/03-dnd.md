# What can be dragged in the project panel?

Type: grilling
Status: resolved

## Answer

User: **everything, across files**: reorder channels within an axis group, move channels to other axis
groups (also in other scope files, via the file tabs as drop targets), reorder axis groups and move them
to other scope files. Holding Ctrl (Windows/Linux) or Alt/Option (macOS) while dropping copies instead
of moving.
