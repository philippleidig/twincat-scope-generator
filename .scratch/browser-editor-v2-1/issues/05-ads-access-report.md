# Which TMC members can be reached by ADS symbol name and recorded by Scope

**V** = verified (source given). **A** = assumption or inference. The repo was not modified.

The most important finding: **a PLC .tmc file includes more than the ADS symbol table holds.** It still contains members and types marked `hide`, `conditionalshow` and `tc_no_symbol`. For example, `Global_Variables.TcMcGlobal` has the type `_TCMCGLOBAL`, which carries `hide`, yet it is listed as a `<Symbol>` (Beckhoff TF5550/0w8States TMCs). The offline browser therefore has to filter these out itself.

## Notes for the parser
- `<Hides><Hide GUID/>` hides an older type GUID. It does **not** hide members. **V**: samples
- I found no `TcHideSubItems` markup in any TMC; a GitHub code search for it returned 0 hits. The ADS flag `HideSubItems` (0x02000000) exists only online. **V**: ads-client `ads-commons.ts`
- `ItemType` values observed: `Input`, `Output`, `InOut`. **V**
